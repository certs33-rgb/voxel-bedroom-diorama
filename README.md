# Voxel Bedroom Diorama

An interactive Blade Runner-inspired voxel room, rendered with Three.js.

View: https://certs33-rgb.github.io/voxel-bedroom-diorama/

Drag to orbit, scroll to zoom, and use Pause / Reset View. A modern WebGL-capable browser and internet access to the pinned jsDelivr Three.js modules are required.

The page is served directly from index.html; no build step is required.
